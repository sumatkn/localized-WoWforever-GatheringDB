Community tooling for World of Warcraft: Forever

Gathering information, available offline and right in your tooltips.

A planned lightweight, locally packaged gathering database for WoW: Forever. The initial focus is Skinning: showing what a beast can yield, and reversing that lookup to show which creature levels and zones can produce leather, hides, or scales.

Creature → material

Show possible skinning yields, required skill, creature level, and source location in an in-game tooltip where supported by the dataset.

Material → creature

Hover over Light Leather, hides, or scales to find the relevant beasts, level ranges, and zones without opening a separate database website.

Offline, localized data

Transform approved API responses into a small local dataset, initially targeting Glimpse-compatible imports or standalone WoW addon data. No live API calls from the game client.

ForeverDB API usage and compliance

  • Approval first: the maintainer will request API access through a ForeverDB account, provide this public project URL, a contact email, and agree to the source-credit terms.
  • Correct key scope: API access is for a build-time data tool, not for the public webpage and not for a key distributed with a WoW addon. No website or plugin key will be reused outside its permitted scope.
  • Credentials remain private: keys are never committed, bundled into addon releases, exposed in browser JavaScript, or included in public exports.
  • Limits: free-tier usage is capped at 5,000 requests per day and 30 per minute across the account; requests will handle 429 and Retry-After and will not attempt to evade limits.
  • Request identity: the build-time client will use the X-API-Key header (or documented Bearer authorization) and an identifying User-Agent.
  • Data integrity: retain provenance and game-build metadata; distinguish observed Forever results from Classic-derived or uncertain data; do not fabricate probabilities or observation counts.
  • Redistribution: include visible ForeverDB credit and do not resell, misattribute, or redistribute API credentials. Future releases will respect any additional terms attached to the approved key.
